# Working preferences

- Use skills only when the user explicitly requests a skill. Do not automatically select or run skills based on the task, file type, or keywords.
- Keep small changes proportional to the request: inspect the relevant code, reuse existing patterns, make the change, and run focused verification.
- Do not add design briefs, screenshots, broad audits, repeated review passes, or extra documentation unless the user requests them or they are necessary to verify the requested behavior.
- Do not install or enable skills or automatic hooks unless the user explicitly asks.
