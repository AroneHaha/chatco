# Task 3.1 — Extract shared UI components to components/ui/

## Agent: main

## Work Completed

Created 6 shared UI components in `src/components/ui/` that both admin and conductor sides can use:

### 1. `badge.tsx`
- Enhanced existing shadcn/ui badge with Chatco-specific variants
- Added variants: `success`, `warning`, `danger`, `info`, `neutral`
- Added `status` prop for conductor capacity states (`available`/`standing`/`full`)
- Backward-compatible with original shadcn variants (default, secondary, destructive, outline)

### 2. `modal.tsx`
- Theme-aware: `theme` prop accepts `'dark' | 'light'`
- Dark theme uses admin colors (bg-[#1A2540], border-[#2A3A55])
- Responsive: bottom sheet on mobile, centered dialog on desktop
- Features: backdrop with click-to-close, close button, Escape key, body scroll lock
- Drag handle indicator on mobile

### 3. `glass-card.tsx`
- Frosted glass card with backdrop-blur
- Theme-aware (dark: blue-tinted border, light: neutral border)
- Optional `padded` prop (default: true)

### 4. `metric-card.tsx`
- Stat card: icon, value, label, optional trend indicator
- `iconColor` and `iconBg` optional with sensible defaults (blue)
- Trend supports "up"/"down"/"neutral" directions
- Theme-aware

### 5. `status-badge.tsx`
- Conductor-specific capacity status badge
- Pulsing dot indicator (auto-pulses for "available")
- Size variants: sm, default, lg
- Custom label override support

### 6. `payment-summary-card.tsx`
- Payment breakdown: Total/GCash/Cash/Voucher
- Distinct icon + color per payment method
- Auto-computes total if not provided
- Currency formatting (₱ by default)
- Theme-aware

## Design Decisions
- All components use `'use client'` directive
- Theme prop defaults to `'dark'` since both admin and conductor use dark themes
- Admin colors: `bg-[#1A2540]`, `border-[#2A3A55]`
- Conductor colors: `bg-[#0F2135]`, `border-white/10`
- No existing files were modified (badge.tsx enhanced in-place with backward-compatible additions)
